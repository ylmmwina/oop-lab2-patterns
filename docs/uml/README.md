# UML Diagrams

This directory contains UML diagrams for EduPattern Studio.

The diagrams are written in PlantUML.

## Directory Structure

```text
docs/uml/
├── README.md
├── source/
│   ├── activity-diagram.puml
│   ├── class-diagram.puml
│   ├── component-diagram.puml
│   ├── sequence-diagram.puml
│   ├── state-diagram.puml
│   └── use-case.puml
└── images/
    ├── activity-diagram.png
    ├── class-diagram.png
    ├── component-diagram.png
    ├── sequence-diagram.png
    ├── state-diagram.png
    └── use-case.png
```

## Diagram List

| Diagram | Source | Image | Purpose |
|---|---|---|---|
| Use Case | `source/use-case.puml` | `images/use-case.png` | Shows user interactions with the system |
| Class | `source/class-diagram.puml` | `images/class-diagram.png` | Shows classes and implemented design patterns |
| Component | `source/component-diagram.puml` | `images/component-diagram.png` | Shows high-level software components |
| Sequence | `source/sequence-diagram.puml` | `images/sequence-diagram.png` | Shows test creation and persistence flow |
| Activity | `source/activity-diagram.puml` | `images/activity-diagram.png` | Shows the main workflow |
| State | `source/state-diagram.puml` | `images/state-diagram.png` | Shows test session states |

## Notes

Both PlantUML source files and generated PNG images are included.

The source files make the diagrams editable, while PNG images make them easy to view directly in the repository.
